# Отраслевой справочник

Справочник помогает строить отраслевые запросы и формулировать гипотезы. Это не источник фактов: что реально есть у конкретной организации, берётся только из источников.

Сектора, которые оператор добавил через `add sector`, лежат в `config/settings.json` → `sectors`. Если сектора нет в таблице, формулируй потребности по аналогии с ближайшим.

«Типичный заказчик» — это гипотеза для `next_step` («выйти на CIO через …»). В поле `contact` она не попадает: туда пишется только то, что названо в источнике.
