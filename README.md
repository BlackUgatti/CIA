# MIA — Market Intelligence Agent

Агент рыночной разведки команды Data & Analytics на Claude Code. Раз в неделю он ищет в KZ, AZ и UZ организации с потребностью в ИТ- и data-услугах: ИИ-решения, data governance, внедрение ИС, IT due diligence, дорожные карты. Найденные лиды агент оценивает, проверяет по первоисточникам и складывает в Excel-реестр. Со временем он учится на отметках команды.

## Как устроено

```
.claude/skills/mia/SKILL.md        главная инструкция агента (/mia)
.claude/skills/mia/reference/      справочники: скоринг, поиск, отрасли, форматы, deep
.claude/agents/mia-researcher.md   субагент: поиск по одной стране (Sonnet, параллельно)
.claude/agents/mia-verifier.md     субагент: проверка фактов перед дайджестом
scripts/mia.py                     учёт: run_id, score, статистика, реестр, Excel
config/settings.json               страны, сектора, параметры, watchlist
data/leads.csv                     реестр лидов (источник истины)
data/query_stats.csv               статистика обучения
data/lessons.md                    правила из обратной связи (активирует оператор)
data/exclusions.csv                текущие клиенты, партнёры, blacklist
inbox/                             сюда кладутся файлы с отметками команды
reports/<run_id>.md                еженедельный дайджест
reports/leads.xlsx                 Excel для команды (пересобирается каждый раз)
routine/prompt.md                  промпт для еженедельной облачной рутины
```

Модель отвечает за поиск, чтение и суждение, а скрипт — за арифметику. Поэтому score и статистика считаются одинаково на каждом запуске.

## Команды

`/mia help` · `/mia scan` · `/mia scan KZ` · `/mia scan "Финансовые услуги"` · `/mia deep <ID лида>` · `/mia hot` · `/mia top` · `/mia stats` · `/mia feedback inbox/<файл>` · `/mia settings` · `/mia set hot_threshold 75` · `/mia add exclude "АО Клиент" client` · `/mia report` · `/mia reset stats`

## Еженедельный цикл

1. По понедельникам рутина вливает отметки из `inbox/`, делает скан, коммитит результаты в `main`.
2. Владелец агента передаёт команде `reports/leads.xlsx` и дайджест.
3. Команда заполняет жёлтые колонки на листе «Лиды» (статус BD, оценка, комментарий) и возвращает файл.
4. Владелец кладёт файл в `inbox/` и пушит его в репозиторий. Раз в неделю (5 минут) он переносит проверенные предложения в `data/lessons.md` из «Предложено» в «Активные правила».

## Обслуживание

- Числа в `data/*.csv` вручную не правьте. Если реестр нужно исправить, удалите строку лида целиком и выполните `python scripts/mia.py report`.
- Если скан упал на середине, повторный `start` в ту же неделю продолжит в той же папке `runs/<run_id>`. Повторная загрузка (`ingest`) уже загруженного скана заблокирована.
- Требуется Python 3.10+ и `openpyxl` (без него вместо Excel обновятся только CSV).
